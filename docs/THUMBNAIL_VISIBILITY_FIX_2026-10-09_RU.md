# Превью и границы видимости — 09.10.2026

Исправления в текущем React/Electron checkout. Существующие незакоммиченные изменения сохранены; общий коммит с чужими правками не создавался.

## Поведение

- Загрузка изображения начинается за 600 экранных пикселей от окна. Уже загруженное изображение сохраняется до удаления на 900 пикселей за край. Разные пороги предотвращают колебания состояния возле границы.
- CanvasLayer сохраняет ноды до 1200 экранных пикселей за краем; размер запаса переводится в координаты холста с учётом zoom.
- Видимость определяется координатами контейнера относительно окна. Обрезающие overflow-контейнеры холста больше не заставляют IntersectionObserver преждевременно выгружать источник. Нулевой intrinsic размер незагруженного img не мешает первой загрузке.
- Все картинки используют один таймер проверки геометрии (100 ms), а не отдельные таймеры на каждую картинку. Scroll/resize проверяются сразу; после ухода последнего потребителя таймер и listeners удаляются. Контейнеры без layout (display:none) не удерживают src.
- Нативное loading=lazy не добавляет второй независимый порог к уже управляемой загрузке.
- OptimizedThumbnail всегда создаёт ограниченное по размерам превью; короткая строка data URL не считается доказательством малого разрешения. Полные оригиналы не используются как промежуточный DOM-src.
- SHA-256 всего источника заменяет выборочный ключ, который мог совпадать для разных изображений. Общая задача отменяется после ухода последнего потребителя, включая потребителей объединённых запросов. Отменённая задача не публикует оригинал как fallback.
- Если primary preview не декодируется, UI создаёт новую миниатюру из доступного оригинала. Это подключено к AI Editor input A/B, sequence output и основному output, а также к Image Input master, crop, frames, grid и batch. При отсутствующем primary источнике также используется доступный original fallback.
- В Image Input thumbnail ограничен 512×512 без изменения пропорций и без увеличения маленьких изображений. Основное окно и все режимы используют тот же компонент. Основное изображение вписывается в доступную площадь окна по ResizeObserver и масштабируется вместе с ним. Crop/grid/frames overlay привязаны к вписанному прямоугольнику изображения, а не к полям вокруг него. Для существующих проектов 512px-превью создаётся из оригинала; encoded DOM-source остаётся миниатюрой. Крупный output AI Editor использует превью до 512×512.
- Обработчики drag/copy/view/download/server не переводились на миниатюры. Оригинальные байты и кэш оригиналов сохранены.

## Проверки

- TypeScript: `npm run lint` проходит.
- Production build: `npm run build` проходит; worker собран отдельно. Сохраняется предупреждение Vite о размере основного bundle.
- Новые 8 тестов проверяют безопасную область, разные пороги видимости, контейнер вместо пустого img, очистку listeners, объединение/отмену декодирования, полный content key, восстановление повреждённого preview и 512px UI-source во всех режимах Image Input с сохранением original drag.
- Актуализирован mock модели в существующем тесте OutputPanel под уже присутствующие локальные изменения modelConfig; функциональность теста оригиналов сохранена.
- Визуальная приёмка pan/zoom и измерения FPS/GPU в установленном EXE в этом проходе не проводились. Тесты компонентов используют React harness и подменённый декодер, а не реальные серверные запросы. Установленный EXE не заменялся.

После уточнения размера добавлена проверка вписывания широкого, высокого и квадратного изображения в окно, включая увеличение маленькой миниатюры без изменения пропорций.
